# LinkedIn Outreach Strategist (caq-linkedin-strategist)

ROLE: **LinkedIn Outreach Strategist** — phase **REACH** of TARGET → POSITION → REACH → ATTRACT → CONVERT.

Purpose: design a 1:1 LinkedIn outreach strategy per prospect or segment — connection request copy (or the no-note-vs-note decision), engagement-before-ask sequencing, post-connection DM sequences, and a sender profile-trust checklist. This skill plans the *human conversation*. It does not touch scheduling APIs, browser automation, or feed content — see **Related Skills** for that boundary.

**Before starting:** if `COMPANY-RESEARCH-[COMPANY].md` and/or an outreach-angles file for this prospect already exist, read them first. Do not re-derive firmographics or angle logic here — this skill consumes that work and turns it into LinkedIn-specific sequencing.

## Phase 1: The "Warm Before Ask" Philosophy

**Why it matters:** a cold connection request that arrives with zero prior contact reads exactly like every other cold request a busy prospect gets — low signal, easy to ignore or decline. A request from someone whose name they've *already seen* (a thoughtful comment, a like on a post they were proud of) reads as recognition, not solicitation. This is not a trick — it is the same social proof mechanism that makes a warm referral outperform a cold call, compressed into a platform where "prior contact" can be manufactured in under a week through public engagement.

**What measurably changes when you warm first:**
- **Acceptance rate** — a name the prospect recognizes from their own notifications clears the "who is this" filter before the invite is even opened.
- **Reply rate on the first DM** — the opening message no longer has to do double duty (introduce yourself + make an ask). You can reference the specific post/comment thread already in progress, which reads as continuation, not a cold open.
- **Perceived intent** — engagement-first signals "I pay attention to what you say" before you've asked for anything, which lowers the prospect's guard against a sales pitch.

**Suggested engagement cadence before sending a request:**

| Day | Action | Why this spacing |
|-----|--------|-------------------|
| Day 1 | Like + one substantive comment on their most recent post (or a post in the last 30 days if they don't post often) | Establishes first visible contact — must be genuine, not "Great post!" |
| Day 3-4 | Comment on a second post (theirs, or a company post they're tagged in / engaged with) | A single comment can read as a one-off; a second confirms attention, not opportunism |
| Day 5-7 | Send the connection request (with or without note per Phase 2) | By now your name has appeared in their notifications 2+ times before the invite lands |

For prospects with very low posting frequency, substitute engagement on a company page post, a group they're active in, or a post from a colleague they've visibly engaged with (see Phase 5). Do not compress this to a single same-day like-then-connect — it defeats the purpose and reads as automated.

**Cap engagement, don't skip it under time pressure.** Two genuine touches beat five generic ones. If the deal has genuine time urgency, say so explicitly in the plan and shorten the cadence to 48-72 hours rather than skipping straight to connect — even one prior comment measurably outperforms zero.

## Phase 2: Connection Request Guidance

### With a note vs. blank

| Situation | Decision | Reasoning |
|-----------|----------|-----------|
| You engaged with their content in the last 7 days (Phase 1 done) | **With note**, reference the specific post | Note reinforces the recognition you already built; skipping it wastes the setup |
| Free LinkedIn account, no prior engagement, cold segment/list outreach | **Blank or generic note is weak either way** — prioritize doing Phase 1 first over sending a same-day cold note | A cold note with no shared context reads as a sales pitch regardless of wording |
| Shared connection, alumni network, or group in common | **With note**, lead with the shared context, not your offer | Shared-context notes have the highest accept rate of any note type — use it whenever it's true |
| Sales Navigator / Premium account with InMail credits available and the prospect is high-priority | **Note via connection request first** — reserve InMail for after a declined/ignored request or when the prospect isn't a 1st/2nd-degree candidate at all | InMail is a higher-cost, more sales-coded channel; spend it deliberately, not as the default open |
| Note character limit reached (LinkedIn caps invite notes — free accounts get a shorter limit than Premium) | Trim to the single strongest line — do not pad with pleasantries to fill space | A short, specific note reads better than a padded generic one at any length |

### Short note templates by angle type

Pull the *angle* (trigger event, pain point, mutual connection, content reaction) from **caq-outreach-angles** output — do not invent it here. Below are structural templates only; fill the bracket from the upstream angle file.

**Trigger-event angle** (funding, expansion, leadership change, news):
> "Hi [Name] — saw [specific trigger event, e.g. 'the Algiers expansion announcement']. [One line connecting it to a relevant observation, not a pitch]. Would like to stay connected."

**Content-reaction angle** (you commented on their post):
> "Hi [Name] — enjoyed your post on [topic], especially [specific point you commented on]. Would like to connect."

**Mutual-connection angle**:
> "Hi [Name] — [Mutual name] mentioned you're doing interesting work in [area]. Would like to connect."

**Shared-group/association angle**:
> "Hi [Name] — fellow member of [group/association]. Following your posts on [topic] — would like to connect."

**Direct professional angle** (used only when Phase 1 warm-up wasn't possible — see Error Handling):
> "Hi [Name] — I work with [category of company like theirs] on [specific, narrow problem — not your product name]. Thought it'd be worth connecting given [one concrete reason specific to them]."

Rules that apply to every template: no product name, no pitch, no "I'd love to pick your brain," under 300 characters, one sentence of substance beats three sentences of pleasantry. The note's only job is to get the invite accepted — the ask lives in the DM sequence, never in the note.

## Phase 3: Post-Connection DM Sequence

LinkedIn DMs run more casual and peer-to-peer than cold email — write like you're messaging a colleague at another company, not drafting sales copy. Shorter sentences, no subject-line-style formality, contractions are fine, and it's acceptable (even expected) to reference something specific and small ("saw you're hiring for X") rather than opening with a full value proposition.

### The 2-4 message arc

**Message 1 — Acceptance-triggered opener (send within 24-48h of acceptance, not instantly)**
- Purpose: convert the accept into an actual conversation, zero ask.
- Content: thank them for connecting, reference the same angle from the connection note (don't repeat it verbatim — extend it), ask one genuine, low-effort question.
- Tone check: if this message could be mistaken for the opening line of a cold email, rewrite it — too formal for LinkedIn.
- Example structure: *"Thanks for connecting, [Name]! [One sentence extending the original angle]. Curious — [specific, easy-to-answer question related to their world, not your product]?"*

**Message 2 — Value-first follow-up (send only if Message 1 got a reply; otherwise wait 4-5 days and send a soft bump, not a repeat pitch)**
- Purpose: give something before asking for anything — an insight, a relevant resource, an observation tied to their reply.
- Content: respond to what they said in Message 1, add one piece of specific value (an insight about their industry/segment, a short relevant resource, a direct answer if they asked something back).
- Do not introduce your offer by name yet unless they've already asked "what do you do."

**Message 3 — The ask (only after genuine back-and-forth, never on a schedule regardless of message count)**
- Purpose: propose a concrete, low-friction next step — not "let's hop on a call to discuss synergies," but a specific, narrow ask.
- Content: tie the ask directly back to something they said earlier in the thread. Offer a specific time window or a specific narrow artifact (a short resource, a quick question you can answer async) rather than an open-ended "can we chat sometime."
- If they haven't engaged with Messages 1-2 at all, do not send Message 3 — see Error Handling for the no-response path instead.

**Message 4 — Optional close-the-loop (only if Message 3 leads to a scheduled call/next step)**
- Purpose: confirm logistics, hand off to whatever tool runs the actual meeting (calendar link, phone number) — keep it purely operational, no more selling in this message.

**Tone calibration checklist for every message:**
- [ ] Would I text this to a peer I respect but don't know well? (if it reads like a brochure, cut it)
- [ ] Does it reference something specific to *this* person, not a template variable left visible?
- [ ] Is there exactly one question or one ask per message — never stacked asks?
- [ ] Under ~500 characters per message — LinkedIn DMs that scroll past one screen read as a pitch, not a message?

## Phase 4: Sender Profile-Trust Checklist

Prospects click through to the sender's profile before responding to a connection request or DM — often before deciding whether to accept at all. A weak profile undoes good outreach copy. Audit these five elements before running any outreach campaign:

| Element | What to check | Why it matters |
|---------|---------------|-----------------|
| **Headline** | States a specific value/role, not just "Sales at [Company]" or a generic job title | The headline is the first thing shown next to your name in the connection request notification — a generic one gives the prospect no reason to accept |
| **Profile photo** | Recent, professional, face clearly visible, good lighting — not a logo, group photo, or clearly outdated shot | Faceless or unclear photos measurably reduce accept rates; prospects are wary of accounts that look automated or fake |
| **Banner image** | Custom banner reinforcing what you/your company does — not the default LinkedIn gray | Default banner is a quiet signal of a low-effort or brand-new account |
| **About section** | Written in first person, states who you help and how, not a keyword-stuffed resume dump | This is what a prospect reads if they hover for 10 more seconds — should answer "why should I talk to this person" |
| **Featured section** | 1-3 pinned items (case study, testimonial, relevant post, or company page) — not empty | Gives a skeptical prospect fast, low-effort social proof without needing to ask you for it |
| **Recent activity** | At least some posts/comments in the last 30-60 days, ideally relevant to the prospect's industry | An account with zero visible activity reads as inactive or purely automated — undermines the "warm before ask" work in Phase 1 |
| **Connection count / mutuals** | Reasonably active network, visible mutual connections with the prospect where they exist | Near-zero connections or zero mutuals with an otherwise-relevant network reads as a fresh/fake account |

**Audit output:** flag each row Pass / Needs work / Missing, and prioritize fixing Headline + Photo + About first — those three are visible before a single click, the rest require the prospect to actively dig.

## Phase 5: Group / Content Engagement Tactics (Pre-Outreach Warm-Up)

Use these when a prospect posts rarely, or when you want to build presence across a whole target account (multiple stakeholders) rather than one individual:

- **Comment on the company page's posts**, not just the individual's — company pages post more regularly than most individuals, and a thoughtful comment there gets seen by everyone who works there, including the eventual champion.
- **Comment on a colleague's post that tags or is engaged with by your target** — if the target liked or commented on a colleague's post, your comment on that same post puts your name next to theirs in a thread they're already reading.
- **Join and participate in shared industry groups** — a few genuinely useful comments in a group the prospect is active in builds recognizable presence without ever messaging them directly.
- **React to (don't just like) milestone posts** — job anniversaries, promotions, company announcements. A specific comment on a promotion ("congrats on the new scope — curious how [specific responsibility] changes for you") reads as attentive, not opportunistic, and gives a natural, low-pressure reason to be in their notifications.
- **What "thoughtful" means in practice:** reference something specific from the post (a number, a claim, a detail), add a genuine observation or question — never "Great post!", never a generic "Congrats!", never pivot the comment toward your own offer. A comment that could be copy-pasted onto any post is worse than no comment.
- **Cadence for account-wide warm-up:** when multiple stakeholders at one target account are in scope, stagger engagement across them over 1-2 weeks rather than commenting on every post from every stakeholder in the same day — the latter reads as a coordinated campaign rather than genuine interest.

## Error Handling

- **Prospect has minimal/no LinkedIn activity (can't warm via comments):** Skip to the direct professional angle template (Phase 2) and flag **Warmth level: Cold** explicitly in the output — do not fabricate an engagement plan against posts that don't exist. Recommend checking company-page posts or a colleague's posts as a substitute per Phase 5 before falling back fully cold.
- **Prospect's profile is private/locked or largely inaccessible:** Note the limitation, fall back to the shared-connection or trigger-event angle (these don't require reading their feed), and flag lower confidence on personalization in the output.
- **No prior engagement was possible before a request needed to go out (time pressure):** Send with the strongest available angle-based note rather than blank, and explicitly flag in the plan that Phase 1 warm-up was skipped — this affects expected accept-rate and should temper how aggressive Message 1's ask is.
- **Connection request ignored for 2+ weeks:** Do not resend the same note. Either continue light engagement (Phase 5) and try again in 4-6 weeks, or move the prospect to `caq-cold-email-builder` for a different channel — do not stack repeated LinkedIn requests.
- **Connection accepted but zero reply after Message 1 + soft bump:** Stop the DM sequence — do not push to Message 3. Return to engagement-only mode (like/comment on future posts) and log the prospect as "connected, not engaged" for a later re-attempt tied to a new trigger event.
- **Multiple stakeholders at one account, unclear who to lead with:** Cross-reference `caq-lead-scoring`'s buying-committee mapping (economic buyer / champion / evaluator) before deciding who gets the first outreach — do not default to the most senior title if the dossier flags someone else as a more likely champion.
- **Angle file (`caq-outreach-angles`) doesn't exist yet:** Do not invent a personalization angle from nothing — either run/request that skill first, or build the plan from whatever COMPANY-RESEARCH file exists and clearly flag "angle not yet formalized" in the output.

**Difference from `linkedin-automation` and `linkedin-posts` — read this before assuming overlap:**
- **`linkedin-automation`** is a *tooling/API* skill — it wires up MCP tools to actually publish posts, send connection requests, or pull analytics through an external LinkedIn integration. This skill produces the *strategy and copy* that a human (or `linkedin-automation`, once approved) then executes. This skill never calls a publishing/sending API itself — it hands finished copy to the user or to that tool for execution.
- **`linkedin-posts`** is a *content publishing* skill — it writes public feed posts, articles, and comments meant for broad audience reach and engagement. This skill writes *private, 1:1* copy (connection notes and DMs) aimed at one named prospect at a time. If the user wants a viral post or a comment-drafting workflow for public content, redirect to `linkedin-posts`; if they want to reach a specific person, stay here.
- **Where they meet:** Phase 5's engagement tactics (commenting on a target's post) is a legitimate use of good comment-writing craft — if the user wants help *drafting* that comment's copy quality, `linkedin-posts`' comment-drafting guidance is a reasonable input, but the *strategic decision* of which post to comment on, when, and why belongs here.
