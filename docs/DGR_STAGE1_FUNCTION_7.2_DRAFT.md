## Official generic structure recovered — TABLEAU 7.2.A

IATA's "Orientations" guide (source #5) devotes a numbered subsection to each
CBTA function (7.1, 7.2, 7.3, …), each with its own table. **TABLEAU 7.2.A**
(PDF pages 27–28 of that document, printed pages 23–24) is titled *"Exemple
de liste de tâches pour le personnel chargé du traitement ou de
l'acceptation des marchandises présentées comme du fret général"* — this is
IATA's own generic task list for exactly Function 7.2, not a
KOST-house-derived structure. It has **one** qualification-level column,
headed **"Traitement/acceptation du fret"** — unlike Function 7.1's Table
7.1.A, which has two separate columns (Classification / Préparation). This
is a genuine structural difference from Function 7.1, confirmed by direct
inspection, not an assumption.

The table covers three of the framework's numbered top-level blocks — **0**,
**3**, and **7** — and explicitly omits Blocks 1 and 2 (Classification /
Préparation d'expédition), which belong to Function 7.1 (shipment
preparation) rather than 7.2 (general-cargo acceptance staff who must detect
and refuse hidden/undeclared DG, not classify or pack declared DG shipments).
This matches the KOST course's own framing (see its "Limites" slide,
p. 44–45, distinguishing passenger provisions from cargo-loading provisions)
and is a structural fact, not an inference on my part.

## Explicit SOURCE GAP notes

1. **0.4.3 "Envisager de multiples dangers" — SOURCE GAP.** No slide, exam
   question, or practice-book question in the real KOST Function 7.2
   material addresses subsidiary/multiple-hazard determination as a
   distinct taught point. The only adjacent material is Table 2.3.A's own
   text (a different source document, not the KOST course) mentioning
   "sans danger subsidiaire" in passing for one aerosol entry — that is not
   evidence of Function 7.2 training actually covering this sub-task. Do
   not draft a question against this sub-task without either finding
   additional KOST material or explicitly sourcing it to the DGR text
   directly (Tier A) in a later pass.
2. **7.1 vs 7.2 (accident vs incident reporting) — thin, merged evidence.**
   Both share a single slide (p.110) with no clear conceptual separation in
   the KOST material between "accident" and "incident." This is not an
   absence (something is taught), but it is not clean independent evidence
   for two separate leaf sub-tasks either. Recorded honestly rather than
   forcing two distinct question pools from one shared slide.
3. **0.2.3 (passenger provisions) and 0.5.1 (marking) are adequate but
   shallow** — the course summarizes/points to reference material (Table
   2.3.A; general marking criteria) rather than developing multi-slide
   depth the way it does for hidden-DG detection (0.2.2), classes (0.4.1),
   labelling (0.5.2), or cargo acceptance (3.4.1/3.4.2). Not a gap, but a
   depth asymmetry worth carrying into Stage 2A's source-yield decisions —
   exactly the kind of "thin sourcing wins over artificial question
   volume" principle already established for Function 7.1.
4. **Regulatory paragraph numbers are Tier B, not yet Tier A-verified.**
   Every "DGR x.y.z" citation above is copied from what the KOST slide
   itself displays; none of them has been checked against the current
   IATA DGR 67th Edition (French, Addendum 1) text in this pass, and the
   one DGR edition document present in this function's own source folder
   (66th Edition Addendum, 2025) is not the current baseline either. A
   future Tier A pass for Function 7.2 must not assume any of these
   section numbers are unchanged in the 67th Edition.
